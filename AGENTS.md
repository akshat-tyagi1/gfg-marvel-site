# Project Rules — Protocol: Doom Event Site

## Project
Single-page Marvel/Doctor Doom-themed event landing page for
GeeksforGeeks Student Chapter, Bennett University. Static frontend
only — no backend, no database, no auth.

## Tech Stack
Plain HTML/CSS/JS (or React if agreed) — no framework unless needed.
Self-contained, deployable as a static site.

## Rules
- Read CONTEXT.md before writing any event content — do not invent
  dates, prizes, or details not listed there. If something's missing,
  ask, don't guess.
- Build one section at a time (hero → event info → tracks → timeline
  → prizes → registration CTA). Confirm each looks correct before
  moving to the next.
- After any visual change, check it at mobile, tablet, and desktop
  widths — don't assume desktop-only.
- Keep dependencies minimal — no heavy libraries unless there's a
  specific need (e.g. GSAP only if we agree we need scroll animation).
- If a design decision is ambiguous, ask before proceeding.
- Never push/commit to GitHub without me reviewing first.
